# CollieH Collection — كوليه كوليكشن

موقع متجر مجوهرات مستقل. المجلد كامل وجاهز للنقل إلى دومين خاص.

## التعديل
في آخر `index.html` قسم «إعدادات المتجر»:
- `CONFIG.whatsapp` رقم واتساب بالصيغة الدولية بدون +
- `CONFIG.instagram` رابط حساب إنستغرام
- `PRODUCTS` القطع: الاسم، الفئة، اللون، الوصف. صورة كل قطعة في `assets/<id>.webp`

## النقل إلى دومين خاص (GitHub Pages)
1. أنشئ مستودعًا جديدًا وانسخ محتوى هذا المجلد إلى جذره.
2. أضف ملف `CNAME` يحتوي اسم الدومين، مثل `colliehcollection.com`.
3. فعّل Settings ← Pages ← Branch: main / root.
4. في لوحة الدومين أضف سجلات A الأربعة لـ GitHub Pages وسجل CNAME لـ www.
5. في موقع حسام غيّر `COLLIEH_URL` إلى الدومين الجديد.

يعمل أيضًا على أي استضافة عادية: ارفع محتوى المجلد كما هو.
